# Summary

The Treebank of Pāli contains 158 sentences (1,764 tokens) of grammatical and syntactic annotation based on the Mahāpadānasutta (DN 14), the fourteenth sutta of the Dīgha Nikāya. It provides the first standardized Universal Dependencies framework relevant to the morphosyntax of a Middle Indo-Aryan language, as an essential machine-readable data for Pāli NLP research.

# Introduction

The Treebank of Pāli currently contains 158 sentences with 1,764 tokens chosen from the Mahāpadānasutta (the fourteenth sutta of the Dīgha Nikāya).  Lexical, morpho-syntactic, and dependency information has been initially generated using a prompt-engineered Large Language Model (Gemini 3.1 Pro) workflow in a few-shot setting, and further validated and corrected through a linguist-in-the-loop manual expert process. The annotation guidelines adapt the Vedic Sanskrit conventions to accommodate Pāli's specific morphosyntax, introducing seven language-specific Pāṇinian compound subtypes and standardizing lemmas to the 3rd-person singular present indicative for verbs.
